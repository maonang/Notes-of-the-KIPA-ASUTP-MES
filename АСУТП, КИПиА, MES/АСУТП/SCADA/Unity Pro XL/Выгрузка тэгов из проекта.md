# Выгрузка тэгов из проекта

1. Открыть проект
2. В структуре проекта выбрать папку "Variables & FB instances"
3. ПКМ -> Export
4. Указать каталог для выгрузки в формате *.XSY
5. Открыть таблицу Excel с макросами "C:\Users\Public\Documents\Schneider Electric\Unity Pro\Extras\Excel Import Export Tool\Unity Variables Management.xlsm"
6. На панели инструментов открыть вкладку надстройки "XSY Management"
7. Настроить обработчик файлов через кнопку "Settings" на панели инструментов
8. Открыть файл для обработки через кнопку "Open File"
