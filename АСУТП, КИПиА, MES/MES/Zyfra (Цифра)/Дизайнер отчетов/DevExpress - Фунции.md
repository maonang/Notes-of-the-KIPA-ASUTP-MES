# DevExpress - Фунции

## Агрегатные
| Функция | Описание | Пример |
| --- | --- | --- |
| `Avg()` | Вычисляет среднее для значений выражения в коллекции. | `Avg(Выражение)` |
| `Count()` | Возвращает количество объектов в коллекции. | `Count()` |
| `Exists()` | Определяет имеются ли объекты в коллекции. | `Exists()` |
| `Max()` | Возвращает максимальное заначение выражения в коллекции. | `Max(Выражение)` |
| `Min()` | Возвращает минимальное заначение выражения в коллекции. | `Min(Выражение)` |
| `Single()` | Возвращает один из объектов в коллекции. | `Single()` |
| `Sum()` | Возвращает сумму всех значений выражения в коллекции. | `Sum(Выражение)` |

## Логические
| Функция | Описание | Пример |
| --- | --- | --- |

| | | `Iif( GetYear([date_value]) == 2050 , 'Итого', [date_value] )` |
| `InRange(, , )` |  |  |
| `IsNull()` | Возвращает Истина, если значение NULL. | `IsNull(Value)` |
| `IsNullOrEmpty()` | Возвращает Истина, если строка нулевая, или имеет нулевую длину. | `IsNullOrEmpty(String)` |

## Математические
| Функция | Описание | Пример |
| --- | --- | --- |
| `Abs()` | Возвращает абсолютное, положительное значение числового выражения. | `Abs(Value)` |
| `Sqr()` | Возвращает квадратный корень числа. | `Sqr(Value)` |
| `Cos()` | Возвращает косинус угла, заданного в радианах. | `Cos(Value)` |
| `Sin()` | Возвращает синус угла, заданного в радианах. | `Sin(Value)` |
| `Atn()` | Возвращает арктангенс числа(угол в градусах или в радианах, тангенс которого равен данному значению)` | `Atn(Value)` |
| `Exp()` | Возвращает значение экспоненты | `Exp(Value)` |
| `Log()` | Возвращает натуральный логарифм указанного значения. | `Log(Value)` |
| `Log(, )` | Возвращает логарифм с основанием Base указанного значения. | `Log(Value, Base)` |
| `Rnd()` | Возвращает случайное число, меньше 1 и больше или равное 0. | `Rnd()` |
| `Tan()` | Возвращает тангенс угла, заданного в радианах. | `Tan(Value)` |
| `Power(, )` | Возвращает указанноое значение в степени Power. | `Power(Value, Power)` |
| `Sign()` | Возвращает положительное (+1), нулевое (0), или отрицательное (-1) значение выражения. | `Sign(Value)` |
| `Round()` | Округляет значение к ближайшему целому. | `Round(Value)` |
| `Round(, )` | Округление значения до ближайшего целого, или до определенного колличества десятичных знаков. | `Round(Value, Precision)` |
| `Ceiling()` | Граничное значение. Возвращает наименьшее целое, больше или равное вычисленному выражению. | `Ceiling(Value)` |
| `Floor()` | Возвращает максимальное целое значение, меньше или равное значению выражения. | `Floor(Value)` |
| `Max(, )` | Возвращает максимальное из указаных значений. | `Max(Значение1, Значение2)` |
| `Min(, )` | Возвращает минимальное из указаных значений. | `Min(Значение1, Значение2)` |
| `Acos()` | Возвращает арккосинус числа(угол в градусах или в радианах, косинус которого равен данному значению)` | `Acos(Value)` |
| `Asin()` | Возвращает арксинус числа(угол в градусах или в радианах, синус которого равен данному значению)` | `Asin(Value)` |
| `Atn2(, )` | Возвращает угол, тангенс которого в радианах равен частному двух выражений | `Atn2(Value1, Value2)` |
| `BigMul(, )` | Возвращает 64-битное целое, содержащее произведение двух 32-битных целых величин. | `BigMul(Value1, Value2)` |
| `Cosh()` | Возвращает гиперболический косинус угла, заданного в радианах. | `Cosh(Value)` |
| `Log10()` | Возвращает десятичный логарифм указанного значения. | `Log10(Value)` |
| `Sinh()` | Возвращает гиперболический синус угла, заданного в радианах. | `Sinh(Value)` |
| `Tanh()` | Возвращает гиперболический тангенс угла, заданного в радианах. | `Tanh(Value)` |
| `ToInt()` | Конвертирует Value в эквивалентное 32-битное целое число со знаком. | `ToInt(Value)` |
| `ToLong()` | Конвертирует Value в эквивалентное 64-битное целое число со знаком. | `ToLong(Value)` |
| `ToFloat()` | Конвертирует Value в эквивалентное 32-битное число одинарной точности с плавающей запятой. | `ToFloat(Value)` |
| `ToDouble()` | Конвертирует Value в эквивалентное 64-битное число двойной точности с плавающей запятой. | `ToDouble(Value)` |
| `ToDecimal()` | Конвертирует Value в эквивалентное десятичное число. | `ToDecimal(Value)` |

## Строковые
| Функция | Описание | Пример |
| --- | --- | --- |
| `Trim` | Удаляет все предшествующие и окончательные пробелы. | `Trim(String)` |
| `Len` | Возвращает число символов в строке, или число байт, требуемых для сохранения значения. | `Len(Value)` |
| `Substring('', , )` | Возвращает подстроку, начиная с позиции StartPosition и длиной Length символов. | `Substring(String, StartPosition, Length)` |
| `Substring('', )` | Возвращает подстроку, начиная с позиции StartPosition | `Substring(String, StartPosition)` |
| `Upper()` | Возвращает строку в верхнем регистре. | `Upper(String)` |
| `Lower()` | Возвращает строку в нижнем регистре | `Lower(String)` |
| `Concat` | Возвращает строковое значение, содержащее сцепление всех строк с первой. | `Concat(String1, ... , StringN)` |
| `Ascii()` | Возвращает ASCII код крайнего левого символа строки | `Ascii(String)` |
| `Char()` | Конвертирует ASCII код в символ. | `Char(Number)` |
| | | `'Погр.' + char(10) + '%'` |
| `ToStr()` | Возвращает строковое представление объекта. | `ToStr(Value)` |
| `Replace('','', '')` | Возвращает копию строки, в которой подстрока SubString2 заменена строкой String3. | `Replace(String, SubString2, String3)` |
| | | `Replace( FormatString( '{0:# ### ##0.00}', [acc_value] ), '.', ',' )` |
| `Reverse('')` | Меняет порядок символов в строке на противоположный. | Reverse(String) |
| `Insert('', , '')` | Вставляет строку String1 в строку String2 с позиции StartPosition. | `Insert(String1, StartPosition, String2)` |
| `CharIndex('', '')` | Возвращает стартовую позицию строки1 в строке2, начиная с позиции нулевого символа до конца строки. | `CharIndex(String1, String2)` |
| `CharIndex('', '', )` | Возвращает стартовую позицию строки1 в строке2, начиная с позиции StartLocation до конца строки. | `CharIndex(String1, String2, StartLocation)` |
| `Remove('', )` | Удаление всех символов из данного экземпляра начиная с указанной позиции. | `Remove(String, StartPosition)` |
| `Remove('', , )` | Удаляет Length символов строки, начинач с указанной позиции. | `Remove(String, StartPosition, Length)` |
| `PadLeft('', )` | Добавляет к строке пробелы слева, чтобы строка имела длину Length | `PadLeft(String, Length)` |
| `PadLeft('', , )` | Добавляет к строке символы Char слева, чтобы строка имела длину Length | `PadLeft(String, Length, Char)` |
| `PadRight('', )` | Добавляет к строке пробелы справа, чтобы строка имела длину Length | `PadRight(String, Length)` |
| `PadRight('', , )` | Добавляет к строке символы Char справа, чтобы строка имела длину Length | `PadRight(String, Length, Char)` |
| `StartsWith('', '')` | Возвращает Истина, если начало строки совпадает с параметром StartString; иначе, возвращается False. | `StartsWith(String, StartString)` |
| `EndsWith('', '')` | Возвращает Истина, если конец строки совпадает с параметром EndString; иначе, возвращается False. | `EndsWith(String, EndString)` |
| `Contains('', '')` | Возвращает Истина, если строка содержит SubString; иначе, возвращается False. | `Contains(String, SubString)` |
| `Join()` | Объединяет элементы указанной коллекции, вставляя запятую между каждым элементом. | `Join(Collection)` |
| `Join(, '')` | Объединяет элементы указанной коллекции, используя указанный разделитель между каждым элементом. | `Join(Collection, Separator)` |
| `NewLine()` | Возвращает строку новой строки, определенную для данной среды. | `NewLine()` |
| `FormatString('')` | Возвращает указанную строку с отформатированными значениями полей. Эта функция может принимать любое количество аргументов. | `FormatString(Format, Value1, ... , ValueN)`
| | | Дата: `FormatString( '{0:dd.MM.yyyy}', AddHours( ?param_date_start, 3 ) )` |
| | | Число: `FormatString( '{0:# ### ##0.00}', [vol_value] )` |
