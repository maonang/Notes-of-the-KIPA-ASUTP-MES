# Сравнение каталогов

## Описание
Предназначена для сравнения двух каталогов с определением отсутствующих файлов и папок. Сканирует указанные директории, сохраняет структуру в базу данных SQLite и выполняет сравнение через SQL-запросы, что обеспечивает высокую производительность даже для больших объёмов данных.

## Назначение
- Сравнение содержимого двух каталогов
- Поиск файлов и папок, которые отсутствуют в целевом каталоге относительно исходного
- Экспорт результатов в текстовые файлы для дальнейшего анализа

## Возможности
- **Асинхронное выполнение** – эффективное использование ресурсов при сканировании
- **Поддержка длинных путей на Windows** – автоматическое преобразование путей в формат `\\?\`
- **Гибкость сканирования** – опция рекурсивного или плоского (только текущий уровень) обхода
- **Прогресс-бар** – визуализация процесса сканирования через `tqdm`
- **Пакетная обработка** – вставка данных в SQLite пачками по 1024 записи для повышения скорости
- **Автоматическая очистка** – временные файлы удаляются после завершения работы
- **Обработка прав доступа** – игнорирование каталогов с ошибками `PermissionError`

## Принцип работы
1. **Сканирование исходного каталога**  
   Все пути сохраняются во временную базу данных `src.db` с пометкой типа (файл/папка).

2. **Сканирование целевого каталога**  
   Аналогично сохраняются пути в `tgt.db`.

3. **Сравнение через SQL-запросы**  
   Выполняются два LEFT JOIN-запроса для определения:
   - Файлов, которые есть в исходном каталоге, но отсутствуют в целевом
   - Папок, которые есть в исходном каталоге, но отсутствуют в целевом

4. **Экспорт результатов**  
   Создаются два файла:
   - `compare_result_missing_files.txt`
   - `compare_result_missing_dirs.txt`

## Ограничения
- Не сравнивает содержимое файлов (только наличие/отсутствие)
- Не отслеживает изменения размеров, дат модификации

## Установка зависимостей
```python
1. pip install --upgrade pip
2. pip install tqdm aiofiles aiosqlite
Примечание:
- tqdm - для прогресс-баров
- aiofiles - для асинхронной работы с файлами
- aiosqlite - для асинхронной работы с SQLite
```
