# Список подписей к рисункам

## Описание
Программа предназначена для автоматического извлечения подписей к рисункам из PDF-файлов, где подписи представлены в виде пар "русский текст / английский текст". Поддерживает два основных типа расположения подписей и три формата записи, что позволяет обрабатывать документы с различной структурой.


## Возможности
- Поддержка двух языков: русский и английский
- Пакетная обработка всех PDF из текущей папки
- Интерактивный выбор режимов работы
- Очистка извлечённого текста от невидимых символов и лишних пробелов
- Сохранение в Excel с форматированием и стилями
- Проверка пустых полей в итоговой таблице

## Режимы работы
### Тип расположения

1. Одна строка — подписи находятся в одной строке с разделителем /
2. Разные строки — русская и английская подписи на отдельных строках

### Тип формата
1. С маркерами — используются слова "Рисунок" и "Figure"
2. Только нумерация — подписи начинаются с номера (например, "1. Текст")
3. Смешанный — комбинация обоих форматов
