# Список подписей к рисункам

## Описание
Предназначен для автоматического извлечения подписей к рисункам из PDF-файлов с сохранением результатов в CSV.

## Возможности
- Поддержка двух форматов подписей в PDF
- Пакетная обработка - все PDF из текущей папки за один запуск
- Очистка извлечённого текста от невидимых символов и лишних пробелов
- Сохранение результатов в CSV с кодировкой UTF-8 BOM (корректно открывается в Excel)
- Итоговая сводка по всем обработанным файлам
- Подробное логирование с временными метками

## Принцип работы
### Режим 1 - одна строка с разделителем `/`

Используется, когда английская и русская подписи находятся в одной строке и разделены символом `/`:

```
Figure 3 – Scheme of the process / Рисунок 3 – Схема процесса
```

В CSV сохраняется только русская часть подписи.

| Страница | Номер рисунка | Название рисунка           |
|----------|---------------|----------------------------|
|       12 |             3 | Рисунок 3 – Схема процесса |

### Режим 2 - отдельные строки

Используется, когда английская и русская подписи расположены на отдельных строках:

```
Figure 3 – Scheme of the process
Рисунок 3 – Схема процесса
```

В CSV сохраняются обе строки.

| Страница | Номер рисунка | Название рисунка 1               | Название рисунка 2         |
|----------|---------------|----------------------------------|----------------------------|
|       12 |             3 | Figure 3 – Scheme of the process | Рисунок 3 – Схема процесса |

#№ Пример использования
1. Скопируйте PDF-файлы в папку со скриптом.
2. Запустите скрипт
3. Выберите режим извлечения (1 или 2).
4. Результаты появятся в папке `results_csv/`.
