# XLSX to JSON Converter and more...

## Описание
Предназначена для преобразования данных из xlsx в формат JSON с учётом особенностей структуры данных. Основная задача - корректная обработка повторяющихся Id, когда одна запись может быть представлена в нескольких строках с частично заполненными полями. Программа объединяет такие строки, заполняя только те поля, которые ранее были пустыми.

Дополнительно реализована логика добавления данных для расчётных тегов (Calculation Tag): извлечение параметров из вложенных JSON-конфигураций, генерация недостающих идентификаторов (tagId), добавление информации о связанных свойствах (переменных) с их типами, тегами, выражениями и параметрами расчёта.

## Возможности
- Объединение строк с одинаковым Id, заполнение только пустых полей;
- Автоматическое преобразование строковых JSON-полей в объекты (Configuration);
- Исключение строк по заданным критериям;
- Удаление ненужных полей на этапе обработки;
- Предотвращение попадания определённых полей в итоговый JSON;
- Добавление параметров для расчётных тегов:
-- Генерация tagId при его отсутствии;
-- Дополнение атрибутов расчетных свойств данными из связанных свойств: par_tag, param_expression, par_calc_type, par_calc_offset, par_calc_period;
- Вывод статистики заполненности полей после обработки;
- Сохранение в JSON с поддержкой кириллицы и специальных типов данных

## Важно перед запуском программы
- В main исправить значение переменной INPUT_FILE = "Файл экспорта 22_04_2026.xlsx" на актуальное наименование файла выгрузки, размещенной рядом с программой.
