# Калькулятор даты и времени

## Описание
Предназначен для работы с датами и временем. Поддерживает сложные операции, дробные интервалы и исключение временных промежутков.

## Назначение
- Выполнение арифметических операций с датами и временем (сложение, вычитание)
- Работа с дробными временными интервалами (например, 1.5 дня, 2.25 часа)
- Расчет свободного времени в течение дня с исключением указанных интервалов
- Поддержка различных форматов ввода дат и времени

## Возможности
- Поддержка трех типов данных: datetime (дата и время), date (только дата), time (только время)
- Операции с дробными интервалами: дни (d), часы (h), минуты (m), секунды (s), годы (y), месяцы (mon)
- Вычисление разницы между двумя датами/временем
- Расчет оставшегося времени в дне с исключением указанных интервалов
- Автоматическое определение формата ввода (дата, время или дата+время)
- Обработка сложных выражений с множественными операциями (например, "10:00 + 1.5h - 30m")
- Нормализация разделителей (поддержка как точек, так и слешей в датах)
- Точные вычисления с использованием Decimal для дробных интервалов

## Принцип работы
- Программа анализирует входную строку, определяя тип данных (дата, время или дата+время)
- Временные интервалы парсятся с поддержкой дробных значений (например, "1.5d" = 1 день 12 часов)
- Применяются арифметические операции с учетом типов данных
- Результат форматируется в читаемый вид
- Для операций с исключением интервалов строится расписание свободного времени

## Особенности
- Автоматическая обработка перехода через полночь в интервалах времени
- Объединение пересекающихся интервалов при расчете свободного времени
- Поддержка как целых, так и дробных значений временных интервалов
- Адаптивное форматирование вывода (секунды показываются только если не нулевые)

## Поддерживаемые форматы ввода
- Дата: `01.01.2025`, `01/01/2025`
- Время: `10:00`, `10:00:30`
- Дата и время: `01.01.2025 10:00`, `01.01.2025 10:00:30`

## Форматы интервалов исключения
- `HH:MM + Nd/Nh/Nm/Ns` - начало + продолжительность
- `HH:MM - HH:MM` - начало - конец

## Примеры использования
### Базовые операции
```
> 01.01.2025 10:00 + 2.5h
========================================
Результат: 01.01.2025 12:30
========================================

> 15:30 - 45m
========================================
Результат: 14:45
========================================

> 01.01.2025 - 25.12.2024
========================================
Результат: 7d
========================================
```
### Дробные интервалы
```
> 10:00 + 1.75h     (1 час 45 минут)
========================================
Результат: 11:45
========================================

> 01.01.2025 + 0.5y (полгода)
========================================
Результат: 02.07.2025
========================================
```
### Сложные выражения
```
> 09:00 + 1.5h - 30m + 15m
========================================
Результат: 10:15
========================================
```
### Расчет свободного времени с исключением интервалов
```
> 01.01.2025 [09:00 + 2h; 13:00 - 15:00; 16:30 + 1.5h]
========================================
Результат:
Оставшееся время в течение дня: 11h 30m
Свободные интервалы:
  • 00:00 - 09:00 (9h)
  • 11:00 - 13:00 (2h)
  • 15:00 - 16:30 (1h 30m)
  • 18:00 - 23:59:59 (5h 59m 59s)
========================================
```
